# Bible Reader content — HT-Haitian,_Haitian_Creole

This repository contains the Bible Reader SD-card content for **HT-Haitian,_Haitian_Creole**.

## Directory layout

- `text/HT-Haitian,_Haitian_Creole/` — all Bible translations and their original nested folder structure.
- `audio/HT-Haitian,_Haitian_Creole/` — audio Bible book folders and chapter MP3s.
- `gospel/HT-Haitian,_Haitian_Creole/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
